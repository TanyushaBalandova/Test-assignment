# Тренажёр (тестовое задание)

Статическое веб-приложение (тестовое задание): тренажёр из 5 вопросов с картинками.
Пользователь вводит ответ, а после прохождения видит таблицу результатов с сравнением
ответов и отметками «верно/неверно».

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | главная страница тренажера |
| `answers.html` | таблица результатов |
| `style/style.css` | стили |
| `js/script.js` | логика тренажёра (вопросы, навигация, проверка)|
| `js/answers.js` | отрисовка таблицы результатов |
| `images/` | иконки (svg/) и картинки вопросов (questions/) |

## Запуск

Способ 1
1. Онлайн: https://tanyushabalandova.github.io/Test-assignment/

Способ 2
1. Скачайте или склонируйте репозиторий с проектом.
2. Откройте файл `index.html` в любом современном браузере (двойным кликом).
3. Никакие серверы или сборщики не требуются — проект работает локально.

## Как пользоваться

1. Введите ответ в поле и нажмите галочку.
2. Переходите между отвеченными вопросами через панель слева.
3. После последнего вопроса откроется `answers.html` с результатами
   (ответы передаются через `localStorage`).
4. Кнопка сброса перезапускает тренажёр с начала.
